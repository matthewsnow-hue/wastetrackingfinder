About

How we build the list

Waste Tracking Finder is independent. It's run by Matthew Snow trading as Sno Automations and is not run by, affiliated with or endorsed by Defra or any regulator. We never describe a product as “approved by Defra”; we say it is on GOV.UK's list of software providers.

Source

Every product and provider comes from GOV.UK's Report receipt of waste: choose a software provider, list updated 23 Oct 2026 (238 products, 237 providers); we last checked our copy against it on 26 Oct 2026. Names are shown exactly as GOV.UK writes them. If GOV.UK removes a product, we remove it.

What we add

  • Site type (186 of 238): our reading of the product's name or its vendor's website, last reviewed 29 Oct 2026. 52 are “Other / not yet categorised” and don't appear in any type filter.
  • Websites (93 of 238): found by hand and checked on 19 Oct 2026. Some are the provider's company site. Where we haven't found one, we link to GOV.UK's list rather than guess.
  • Prices (31 of 238): only prices we read on the vendor's own site, as shown (VAT as stated), each with the date we checked it.
  • PAT exemptions (4): copied from GOV.UK's list. We don't know which scenarios apply.

Order and sponsorship

Lists are A–Z by product name, the same for everyone. Sponsored listings are labelled “Sponsored”, shown in a separate box, use rel="sponsored", and never change the order or contents of any list or guide. If we ever use affiliate links, we'll say so next to the link.
